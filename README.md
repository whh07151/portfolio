# 우현호 백엔드 개발자 포트폴리오

백엔드 개발자 우현호의 프로젝트와 기술 경험을 소개하는 정적 포트폴리오입니다.

## 배포

- **Live:** [https://whh07151.github.io/portfolio/](https://whh07151.github.io/portfolio/)
- **Hosting:** GitHub Pages

## 핵심 구성

- 대표 프로젝트와 담당 역할
- 문제 해결 과정과 검증 가능한 성과
- 프로젝트 저장소·API/DB 명세·사용 가이드 링크
- 경험 수준별 기술 스택
- 모바일 우선 반응형 레이아웃과 다크 모드

## 대표 프로젝트

| 프로젝트 | 역할 | 주요 기술 | 근거 |
|---|---|---|---|
| LunchSync | 팀장·백엔드 리드 | NestJS, PostgreSQL, AWS EC2 | [저장소](https://github.com/whh07151/LunchSync) |
| Thesisfy | 데이터 관리·API 설계 | REST API, 데이터 모델링 | [저장소](https://github.com/SW-PCD/Thesisfy) |
| QueueCheck | Android 프론트엔드 | Kotlin, Firebase Auth, Retrofit2 | 팀 저장소 비공개 |

## 기술

별도 빌드 과정 없이 `index.html` 하나로 동작합니다.

```text
HTML · CSS · Vanilla JavaScript
```

## 로컬 확인

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열거나 간단한 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.
